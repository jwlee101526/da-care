---
device: smartphone
title: 스마트폰 화면 터치가 되지 않음 (Smartphone touchscreen not responding)
---
증상: 화면을 눌러도 반응이 없거나 일부 영역만 터치되지 않습니다.
점검 절차:
1. 화면 보호 필름이나 케이스가 들떠 있으면 제거합니다.
2. 손과 화면의 물기나 이물질을 닦습니다.
3. 전원 버튼을 길게 눌러 강제로 재시작합니다.
4. 최근 설치한 앱 이후 증상이 생겼다면 해당 앱을 삭제합니다.
방문 점검이 필요한 경우: 화면이 깨졌거나 재시작 후에도 같은 영역이 반응하지 않으면 디스플레이 점검이 필요합니다.
