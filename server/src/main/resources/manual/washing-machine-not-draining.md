---
device: appliance
title: 세탁기 배수가 되지 않음 (Washing machine does not drain)
---
증상: 세탁이 끝나도 물이 빠지지 않거나 배수 오류가 표시됩니다.
점검 절차:
1. 전원을 끄고 플러그를 뽑습니다.
2. 배수 호스가 꺾이거나 눌려 있지 않은지 확인합니다.
3. 본체 하단의 배수 필터 덮개를 열어 잔수를 빼고 필터의 이물질을 제거합니다.
4. 겨울철에는 배수 호스가 얼지 않았는지 확인합니다.
방문 점검이 필요한 경우: 필터 청소 후에도 배수되지 않거나 배수 펌프에서 소음이 나면 펌프 점검이 필요합니다.
