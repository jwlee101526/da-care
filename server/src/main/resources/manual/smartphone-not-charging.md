---
device: smartphone
title: 스마트폰이 충전되지 않음 (Smartphone not charging)
---
증상: 케이블을 연결해도 충전 표시가 나타나지 않거나 충전이 끊겼다 이어지기를 반복합니다.
점검 절차:
1. 다른 케이블과 충전기로 바꿔 연결해 봅니다.
2. 충전 단자 안의 먼지를 전원을 끈 상태에서 부드러운 솔로 제거합니다. 금속 도구는 사용하지 마세요.
3. 기기가 젖었다면 완전히 마를 때까지 충전하지 않습니다.
4. 기기를 재시작한 뒤 다시 충전합니다.
방문 점검이 필요한 경우: 여러 충전기로도 충전되지 않거나 충전 중 기기가 과도하게 뜨거워지면 충전 단자 또는 배터리 점검이 필요합니다.
